ติดตั้งบน Windows · 3 ก้าว (no-admin)

# 1) Node ผ่าน fnm (user-level) winget install Schniz.fnm fnm install --lts ; fnm use lts-latest # 2) Claude Code npm install -g @anthropic-ai/claude-code # 3) API key (แล้วเปิด terminal ใหม่) setx ANTHROPIC_API_KEY "sk-ant-xxxx" # ✅ ตรวจ claude --version

ความปลอดภัย & ค่าใช้จ่าย

  • 🔑 ใช้ ANTHROPIC_API_KEY — อย่าแชร์ key
  • 🚫 อย่า commit secret ลง git → ใช้ env var
  • 💰 ตั้ง spend limit ใน Console — ระวังงานวน/ยาว
  • 👀 อ่าน diff / คำสั่ง ก่อนกด allow เสมอ
  • 🔒 ระวังคำสั่งบนเครื่องที่มี root (capstone)
  • 🔌 SSH ต้อง non-interactive: StrictHostKeyChecking accept-new
